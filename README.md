# כסף מאמא
התקציב מתחיל ב־600 ₪ לחודש. בחודש הנוכחי אפשר ללחוץ על ״שינוי סכום חודשי״ כדי לעדכן אותו. הסכום החדש חל מתחילת אותו חודש וממשיך בכל חודש שאחריו עד לשינוי הבא. חודשים קודמים שומרים על התקציב שהיה בתוקף בזמנם. קניות נשמרות לפי התאריך שלהן. אין העברת יתרה בין חודשים. מחיקת קנייה מחזירה את הסכום לתקציב של אותו חודש, עם אפשרות ביטול.

## העלאה ל־GitHub Pages
1. העלו את כל הקבצים שבתוך ZIP לשורש המאגר.
2. ב־Settings → Pages בחרו Deploy from a branch, ענף main ותיקיית / (root), ואז Save.
3. פתחו את כתובת האתר ש־GitHub מציג. בטלפון אפשר לבחור ״הוספה למסך הבית״.

אין שרת, התקנה או תהליך build. אפשר להשתמש גם ללא אינטרנט אחרי הפתיחה הראשונה. הנתונים נשמרים בדפדפן המקומי ואינם מסתנכרנים בין מכשירים. כפתור הגיבוי מוריד קובץ JSON עם הקניות והיסטוריית הסכומים החודשיים. השחזור ממזג קניות ושינויי תקציב עם הנתונים במכשיר. אם כבר הוגדר במכשיר סכום לאותו חודש, הסכום המקומי נשמר. אפשר לשחזר גם גיבויים מהגרסה הקודמת.
