# כסף מאמא
אפליקציה בעברית לניהול תקציב של 600 ₪ בחודש, מה־1 בחודש ועד תחילת החודש הבא. קניות נשמרות לפי התאריך שלהן; אין העברת יתרה בין חודשים. מחיקת קנייה מחזירה את הסכום לתקציב של אותו חודש, עם אפשרות ביטול.

## העלאה ל־GitHub Pages
1. העלו את כל הקבצים שבתוך ZIP לשורש המאגר.
2. ב־Settings → Pages בחרו Deploy from a branch, ענף main ותיקיית / (root), ואז Save.
3. פתחו את כתובת האתר ש־GitHub מציג. בטלפון אפשר לבחור ״הוספה למסך הבית״.

אין שרת, התקנה או תהליך build. אפשר להשתמש גם ללא אינטרנט אחרי הפתיחה הראשונה. הנתונים נשמרים בדפדפן המקומי ואינם מסתנכרנים בין מכשירים. ניקוי נתוני הדפדפן מוחק אותם; כפתור גיבוי מוריד JSON ושחזור ממזג אותו עם הקניות הקיימות בלי להוסיף כפילויות.
